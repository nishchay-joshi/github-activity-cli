# GitHub User Activity CLI

A simple CLI application that fetches and analyzes a user's recent GitHub activity using the GitHub REST API.

---

# Features

- Fetch recent public GitHub activity
- Analyze Push, Issue, Watch, Fork, and Create events
- Count repository push activity
- Display most active repositories
- Handle API/network errors
- Command-line interface using `argparse`

---

# Error Handling

The application handles:

- Invalid GitHub usernames
- GitHub API rate limiting
- Network connection issues
- Request timeouts
- Unexpected API failures
